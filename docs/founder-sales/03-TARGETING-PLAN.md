# 3) Targeting Plan + Target List

## Targeting criteria

### Primary targets: Small RIA CCOs / Compliance Owners

| Criterion | Signal to look for |
|---|---|
| **Firm type** | SEC-registered RIA, 1–20 advisers, $50M–$1B AUM |
| **Role** | CCO, Chief Compliance Officer, Director of Compliance, Principal (wears compliance hat) |
| **Trigger signals** | Recent SEC exam (public via IAPD); new CCO hire (LinkedIn); firm growth (new adviser registrations on ADV); annual review season (Q4/Q1); compliance job postings |
| **Pain signals** | No dedicated compliance tech on their ADV Part 1A; mentions "spreadsheet" or "manual" process in compliance forums; small ops team (1–3 people doing everything) |
| **Speed to close** | Single decision-maker (CCO = budget holder); no procurement process; can say yes in 1–2 calls |
| **Exclusion** | Already using enterprise compliance platforms (Smarsh, ComplySci, NRS); >20 advisers; unwilling to consider cloud/AI tooling |

### Secondary targets: Compliance Consultants / Outsourced CCO Firms

| Criterion | Signal to look for |
|---|---|
| **Firm type** | Compliance consulting firm or outsourced CCO provider; serves 5–50+ RIA clients |
| **Role** | Managing Principal, Lead Consultant, Outsourced CCO |
| **Trigger signals** | Growing client roster; hiring compliance associates; preparing multiple clients for exams; posting about documentation challenges |
| **Pain signals** | Same manual documentation problem, multiplied across clients; looking for leverage |
| **Speed to close** | Medium — need to see it work for 1–2 clients, then roll out |
| **Distribution upside** | One relationship → many RIA clients onboarded |

## Where to find targets

| Channel | How to use it | Priority |
|---|---|---|
| **LinkedIn** | Search "Chief Compliance Officer" + "RIA" or "registered investment adviser." Filter by company size 1–50. Look for recent job changes, posts about compliance pain, SEC exam mentions. | High |
| **IAPD / SEC EDGAR** | Search SEC Investment Adviser Public Disclosure (IAPD) for small RIAs. ADV filings show firm size, AUM, CCO name. Cross-reference with LinkedIn. | High |
| **Compliance communities** | RIA compliance Slack groups, compliance subreddits, NSCP (National Society of Compliance Professionals), IAA (Investment Adviser Association), local compliance roundtables. | High |
| **Compliance conferences** | NSCP National Conference, IAA Compliance Conference, RIA compliance webinars, local NSCP chapter events. Attend or speak on "AI in compliance." | Medium |
| **Warm intros** | Ask any investors, advisers, or industry contacts for introductions to RIA CCOs. Frame as "diagnostic conversation, not a pitch." | High |
| **RIA custodian ecosystems** | Schwab, Fidelity, Pershing RIA networks — they host compliance events and have directories. | Medium |
| **Compliance consultant networks** | Many consultants are visible on LinkedIn and industry directories. Winning one = distribution. | High |

## List-building action plan (Week 1)

1. **IAPD search:** Pull 50 SEC-registered RIAs with 1–20 advisers, $50M–$1B AUM. Note CCO names from ADV filings.
2. **LinkedIn cross-reference:** Find each CCO on LinkedIn. Note job tenure, recent posts, mutual connections.
3. **Score & prioritize:** Rank by trigger signal strength (recent exam > new hire > generic). Select top 25.
4. **Warm path check:** For each top-25, check if you have a mutual connection who could introduce you.
5. **Segment:** Tag each as "warm intro possible" or "cold outreach."
6. **Load into tracking:** Use the weekly learning loop tracker (Section 9) to manage status and next actions.
