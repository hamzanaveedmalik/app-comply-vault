### Pipeline stages

| Stage | Definition | Exit criteria |
|---|---|---|
| **Identified** | On target list; not yet contacted | Outreach drafted and sent |
| **Outreach sent** | Initial message sent (warm intro or cold) | Response received (positive or negative) |
| **Call scheduled** | Discovery call on calendar | Call completed |
| **Discovery done** | Diagnostic call completed; pain validated | Pilot proposed (or disqualified) |
| **Pilot proposed** | Pilot terms shared (decision guide + MAP) | Pilot agreement (verbal or written) |
| **Pilot active** | Design partner; uploading real meetings | ≥10 meetings processed; mid-pilot go/no-go passed |
| **Converting** | Pilot complete; pricing discussion | Subscription signed |
| **Activated** | Paying customer; implemented + first value | 30-day success criteria met |
| **Disqualified** | Not a fit (wrong ICP, no pain, wrong timing) | Documented reason; revisit date if applicable |

## 8-Week Sprint Calendar

| Week | Focus | Target metrics |
|---|---|---|
| **Week 1** | List building + first outreach batch | 15–25 outreach sent; 3–5 responses |
| **Week 2** | Discovery calls + iterate messaging | 5–8 discovery calls; 2–3 pilots proposed |
| **Week 3** | First pilots kick off + continue outreach | 2–3 pilots active; 3–5 more discovery calls |
| **Week 4** | Pilot support + mid-pilot reviews | 3–5 pilots active; first mid-pilot go/no-go |
| **Week 5** | Iterate based on pilot feedback; expand outreach | 5 design partners active; product iterations |
| **Week 6** | Pilot wrap-ups begin; conversion conversations | First 1–2 conversion conversations |
| **Week 7** | Decision calls with pilot partners | 2–3 paying customer decisions |
| **Week 8** | Close remaining conversions; capture proof points | 3 paying customers; case study material |
