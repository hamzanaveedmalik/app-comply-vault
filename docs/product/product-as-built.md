## 1. Product identity

**ComplyVault** is a multi-tenant compliance documentation platform for Registered Investment Advisers (RIAs).

It converts client interactions — meeting recordings/transcripts and email evidence — into human-reviewed, exam-oriented records that can be sealed, exported, and deposited into systems firms already use.

**Positioning (live marketing copy):**

> Meeting records your CCO can seal for exam documentation — with human review before anything is final.

**Core value loop**

```
Capture → AI triage → Human review & sign-off → Seal / audit pack → Sync out
```

**Guiding principle:** AI surfaces what needs attention; a human decides; consequential decisions and sealed bytes are preserved for exam documentation.

## 2. Who uses it

| Role (code) | UI label | What they do |
|---|---|---|
| `OWNER_CCO` | Owner / CCO | Workspace policy, integrations, media posture, retention, CCO sign-off, seal/finalize, invites |
| `MEMBER` | Compliance Manager | Flag triage, CM review, cockpit read paths |
| `ADVISOR` | Advisor | Certify meeting accuracy; no cockpit write; limited settings |

**Tenancy:** every record is workspace-scoped (`Workspace` + `UserWorkspace`). Users may belong to multiple workspaces and switch active workspace.

**Auth (shipped):** Auth.js v5 — email/password credentials + optional Google OAuth; JWT sessions; email-verification gate on the app shell; invitation accept flow.

**Meeting lifecycle (shipped)**

```
UPLOADING → PROCESSING → DRAFT_READY / DRAFT
  → ADVISOR_CERTIFIED → CM_REVIEWED → CCO_SIGNED_OFF → FINALIZED
```

APIs support certify, CM review, CCO sign-off, batch paths, ready-for-CCO, and revert. Transitions write audit events.

### 3.2 Three-layer human review

1. **Advisor certification** — confirms the record is accurate; can edit fields (versioned).
2. **CM flag triage** — resolve / note / escalate / accept-as-risk / N/A; remediation and evidence links.
3. **CCO sign-off** — reviews escalations; single or batch; finalize with reason.

## 4. Primary user journeys (as built)

### A. Zero-touch Zoom meeting → sealed pack

1. CCO connects Zoom; sets media posture (RETAIN or DISCARD).
2. Zoom recording completes → webhook → ingest → process-meeting (transcribe → extract → flag).
3. Advisor certifies → CM triages flags → CCO signs off → finalize/seal.
4. Sealed bytes land in Object Lock store (when bucket configured); optional SharePoint deposit as convenience copy; optional Zoho note.

### B. Manual upload from any platform

1. Advisor/CCO uploads audio, video, or transcript.
2. Same processing and three-layer review as Zoom.
3. Export draft pack anytime; seal only after finalize path.

### C. Email evidence

1. Connect M365 or Gmail mailbox.
2. Delta sync / ingest jobs build threads and triage items.
3. Link evidence to meetings / clients; export thread packs with custody hashes.

### D. Firm disclosure posture

1. Look up firm by CRD; configure disclosure categories.
2. Approve profile changes (versioned + suppression log).
3. Future meetings’ missing-disclosure detection respects suppression.

### E. Correct a sealed mistake

1. Supersede sealed meeting → new draft chain.
2. Re-review and seal the successor.
3. Supersession chain appears in the audit pack; original seal remains.

## 10. One-paragraph summary (external-safe)

ComplyVault today is a workspace-scoped RIA compliance product that captures meetings (Zoom auto-ingest and manual upload; Teams available in-product), processes them through transcription and structured extraction, surfaces missing-disclosure flags tuned by a firm disclosure profile, and requires advisor → compliance manager → CCO review before a meeting can be finalized into a deterministic audit pack that can be sealed with an append-only ledger and optional SharePoint convenience deposit. Email evidence (M365/Gmail), Ask/search, billing, and an honest public trust page are included. Exam request packs, legal-hold enforcement, SOC 2 certification, and an FCA/UK track are not product claims today.
